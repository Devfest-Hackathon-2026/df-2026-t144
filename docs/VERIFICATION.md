- iOS実機のExpo GoがSDK 58、プロジェクトがSDK 57だったため起動できないことを、提供されたエラー画面で確認。
- Expo 58.0.23、React Native 0.88.1、React 19.3.0へ更新。Expo同梱の互換バージョン表に合わせ、関連モジュール・型定義・ロックファイルも更新。
- 更新後に型チェック、ドメイン9件・サーバー11件のテスト、iOS・Android・Webのバンドル生成が成功。
- `expo install --check`：ネットワーク接続ありで「Dependencies are up to date」を確認。
- `expo-doctor`：20項目すべて成功（診断用のnpmを作業用フォルダに用意して確認）。
- SDK更新後の実機画面・ネイティブ地図・GPS操作の確認は未完了。
- LANサーバーのiOS/Androidマニフェストが`exposdk:58.0.0`を返すこと、および両プラットフォームの開発用バンドルがHTTP 200で取得できることを確認。

## 初回体験と位置情報エラーの改善

- 初回案内から最初の未発見スポットを開き、デモ到着→発見→「発見図鑑で見る」までChromeの390×844表示で操作確認。再読み込み後も発見済み表示が残り、初回案内が再表示されないことを確認。
- ブラウザの位置情報要求を拒否し、理由・サイト設定の案内・デモに戻るボタンが表示され、デモへ復帰できることを確認。現在地は取得していません。
- GPS監視開始時に古い現在地を消去し、最初の位置通知まで取得中表示を維持。20秒通知がない場合は案内を表示し、その後の取得成功で案内を消す処理を追加。
- バックグラウンド移行時に監視と現在地を解除し、復帰時には権限を確認して再開する処理を追加。ネイティブ端末での設定往復、タイムアウト、復帰時のGPS挙動は未検証。
- 変更後の型チェック、既存20件の自動テスト、iOS・Android・Webのバンドル生成が成功。ブラウザ検証時のコンソール警告・エラーはなし。

## 確認済み

- `pnpm typecheck`：成功。
- `pnpm test`：9件成功。GPSの半径・鮮度・精度、寄り道予算、破損データ、デモと現地の分離。
- `pnpm test:server`：11件成功。入力検証、徒歩経路の応答処理、見学込み予算、タイムアウト、API呼出上限。一部API失敗時も残り呼出完了まで同時実行枠を保持。
- `pnpm exec expo export --platform all --output-dir dist`：iOS・Android・WebすべてのJavaScriptバンドル生成成功。これはIPA/APKのビルドや実機テストではありません。
- ChromeでReact Native Webの操作を確認。390×844の画面幅で表示し、目的地変更、5分→10分の変更、探索開始、到着前の発見ボタン無効化、デモ到着、解説の表示、図鑑への保存を確認。
- 再読み込み後も発見済み1件が残り、現地モードにはデモ記録が現れないことを確認。
- 現地モードではGPS未取得中に発見を解放しないことを確認。検証中に現在地の利用許可は与えていません。
- WebマーカーのSVGイベント警告を修正し、地図から正しいスポットを開けることを確認。近接する橋と駅伝碑は略図上で表示をずらし、点線で元の位置につないでいます。
